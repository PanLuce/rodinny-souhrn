Rodinný přehled

Soukromý nástroj jedné rodiny. Každé ráno sestaví e-mailový souhrn z rodinných zdrojů, například ze školního systému, kalendářů a tabulky rozvozu dětí. Aplikace není určená pro veřejnost.

Zásady ochrany soukromí

  • Aplikace žádá o jediné oprávnění: https://www.googleapis.com/auth/spreadsheets.readonly. Tabulky Google jen čte, nikdy je nemění.
  • Z tabulky se čte jen rozpis rozvozu dětí. Slouží výhradně k sestavení souhrnu pro rodinu, která si aplikaci spustila.
  • Přístupový token i načtená data zůstávají jen na počítači, na kterém aplikace běží. Nikam se neodesílají, nikomu se neprodávají a nesdílejí se s třetími stranami.
  • Přístup jde kdykoli odvolat na myaccount.google.com/permissions.
  • Využití dat získaných přes Google API se řídí zásadami Google API Services User Data Policy, včetně požadavků Limited Use.
